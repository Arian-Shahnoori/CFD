# Original MSc Implementation

This folder contains the original Python implementation and report developed during my master's studies for a project on steady two-dimensional heat conduction using the finite-volume method.

The implementation is preserved in its original form to document the development of the project and retain the original code and report alongside subsequent versions.

**Contents**

* `code/`: Original Python implementation developed during the master's project.
* `report/`: Original project report.

## Subsequent Development

The project was subsequently reorganized into a modular codebase and extended with additional numerical solution methods. These later versions are available in the `V1/` and `V2/` directories.

The original implementation is retained for reference, while the later versions document the subsequent development of the solver.
